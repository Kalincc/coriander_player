# Coriander Player：一款使用 Material You 配色的本地音乐播放器。

## 本 fork 的播放数据与升级说明

- 播放队列仅在本次运行期间保留，重启播放器后不会恢复；已不存在的本地文件只会从歌单和历史记录中清理，不会删除你的音乐文件。
- 新增受保护的“我喜欢”歌单：播放界面的爱心按钮会把当前歌曲加入或移出该歌单；它不能被重命名或删除。
- 播放满 30 秒或歌曲时长的 50%（以先达到者为准）才计入有效播放。听歌报告页同时展示最近 20 首播放记录，并提供本周、本月和最近 12 个月的歌曲、歌手、专辑 Top 10 与听歌时长统计。
- 以上数据仅保存在本机，不会上传、同步或修改音频标签。听歌历史、听歌报告、歌单和音乐库索引均位于 `Documents\coriander_player`。

> [!NOTE]
> 本仓库是 [Ferry-200/coriander_player](https://github.com/Ferry-200/coriander_player) 的个人功能增强 fork。原项目及其版权、许可证归原作者和贡献者所有。

## 本 fork 的主要改动

- 支持搜索本地歌词；结果页按歌曲展示歌曲信息及命中的歌词片段，不会因搜索结果自动播放。
- 支持读取音频标签中的本地 LRC 和 Apple/iTunes TTML（逐行、逐字）歌词。
- 调整正在播放歌曲详情页，使当前歌词在可视区域内垂直居中。
- 专辑导航支持“无分类”和“按艺术家分类”，方便快速筛选艺术家。
- 合并同一艺术家的繁体和简体名称，界面统一显示简体名称，同时保留音频文件中的原始艺术家标签。

## 升级、备份与迁移

用户数据统一保存在 Windows 的 `Documents\coriander_player` 目录，而不在软件安装目录中。因此正常覆盖安装、卸载后重新安装或通过新版安装包升级，都不会删除你的歌单、听歌历史、听歌报告和音乐库索引。

从 v1.5.1-kalin.10 升级到 v1.5.1-kalin.11 时，首次运行 `.11` 安装包覆盖原目录即可，不需要先卸载；之后安装版可使用“设置 → 检查更新 → 立即更新”自动下载、校验、覆盖安装并重启。Portable 版请从 Release 页面下载新压缩包，不会自动安装第二份软件。

如需备份，请在播放器关闭后直接复制整个 `Documents\coriander_player` 文件夹；恢复时再覆盖回同一路径。手动删除该文件夹会永久清除歌单（包括“我喜欢”）、听歌历史、听歌报告和音乐库索引，且无法由安装程序恢复。

从旧版首次升级时，旧的 `playlists.json` 会自动保留原有歌曲并补建“我喜欢”歌单。旧的 `playback_queue.json` 会继续保留在磁盘上，但新版不会读取、迁移或删除它；播放队列不会跨重启恢复。播放历史数据缺失或损坏时会以空数据启动；听歌报告会从现有播放历史重新计算，无可用历史时显示空数据，不会自动播放。

## 音乐库建立与扫描

- 已有音乐库索引时，播放器启动只加载索引，不会自动扫描磁盘。
- 首次建库时，请在引导流程中选择音乐文件夹并执行建库。
- 需要更新音乐库时，进入“设置 → 文件夹管理”，选择“立即扫描”。该操作会对已选文件夹执行一次完整递归重建扫描。
- 旧版音乐库索引若未保存扫描根目录，仍可使用已索引的歌曲，但不能直接扫描更新；请到“设置 → 文件夹管理”重新选择文件夹后，再执行“立即扫描”。

## 选择默认歌词
默认情况下，软件会先读取本地歌词。如果没有，则匹配在线歌词。
你可以在正在播放界面的歌词切换按钮展开的菜单中进入选择默认歌词的页面。

![音乐页](软件截图/选择默认歌词.png)
在这个界面中，你可以在本地歌词（如果有）和几个匹配程度高的在线歌词中选择一个作为默认歌词。之后再播放这首音乐时，软件会加载你指定的歌词。

播放时，在线歌词会自动选择得分最高的有效候选；如果候选正文加载或解析失败，会按评分回退尝试其他候选。其余候选仍会保留在“指定默认歌词”中，方便查看和手动选择。在线歌词结果缓存于应用数据目录，不会写入音频文件。

## 编译
1. 开发 flutter 需要的环境
2. 需要编译 Coriander Player（本仓库） 软件本体和 desktop_lyric。[desktop_lyric](https://github.com/Ferry-200/desktop_lyric.git) 也是 Flutter 应用，直接编译即可

## 歌词特性解释
1. lrc歌词的间奏识别   
   在一些lrc歌词中，会使用 **只有时间标签而内容为空** 的一行来表示上一行的结束。如：
   ```
   [02:32.57]光は やさしく抱きしめた
   [02:32.57]那天没能放声大哭的我
   [02:39.94]
   [02:55.18]照らされた世界 咲き誇る大切な人
   [02:55.18]光芒普照整个世界 珍重之人绽放于心
   ```
   如果这一行（第三行）的时间戳和下一行的时间戳之间大于5s，就把这两行之间的时间作为间奏时长  
   **所以，不是所有lrc歌词在间奏时都能显示间奏动画。**
2. 逐字歌词的间奏识别  
   逐字歌词都会给出每一行的开始时间和持续时间，所以识别间奏会简单得多。如
   ```
   [5905,5466]<0,217,0>世<217,383,0>界<600,495,0>は<1095,272,0>と<1367,328,0>て<1695,343,0>も<2038,616,0>綺<2654,752,0>麗<3406,276,0>だ<3682,276,0>っ<3958,504,0>た<4462,1004,0>な
   [23037,5254]<0,255,0>書<255,280,0>架<535,312,0>の<847,592,0>隙<1439,312,0>間<1751,223,0>に<1974,160,0>住<2134,144,0>ま<2278,352,0>う<2630,640,0>一<3270,640,0>輪<3910,190,0>の<4100,680,0>花<4780,474,0>は
   ```
   第一行的开始时间是 5905ms，持续 5466ms；第二行则是 23037ms和 5254ms。可见 5905 + 5466 = 11371，与 23037相差超过 5000ms，所以这两行时间可以插入表示间奏的空白行

## 本次 A 路线更新（v1.5.1-kalin.8）

本版本继续基于 [Ferry-200/coriander_player](https://github.com/Ferry-200/coriander_player) 开发，重点增强本地音乐库的日常使用体验：

- 播放队列仅在当前运行期间有效：支持插入下一首和随机播放，但不会跨重启恢复；旧 `playback_queue.json` 保留但不再读取。
- 新增播放历史：仅记录达到有效播放门槛的本地歌曲，保留最近 12 个月的数据，并在界面展示最近 20 首。
- 新增“我喜欢”歌单：首次使用自动创建，播放页可通过爱心按钮加入或移除；该系统歌单不能被重命名或删除。
- 新增“听歌报告”：支持本周、本月和最近 12 个月视图，展示听歌时长、歌曲数、歌手数、专辑数，以及歌曲/歌手/专辑 Top 10。
- 启动只加载已有索引；首次建库和“设置 → 文件夹管理 → 立即扫描”均执行完整递归扫描。旧索引缺少扫描根目录时，需要重新选择文件夹后才能扫描更新。
- 本地音乐库索引、历史、歌单和报告数据保存在 `Documents\coriander_player`，更新或重新安装播放器不会自动删除这些数据。

发布包由 GitHub Actions 根据 `v*-kalin.*` 标签构建 Windows Portable 和 Setup 安装包，并附带 SHA-256 校验文件。
